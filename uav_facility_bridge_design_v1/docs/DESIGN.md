# 1. 文档定位与实现边界

本文件用于指导本地 Codex 实现一个独立的设施趋向与抵达时间推断模块，不是论文对比基线方案，也不是新的神经网络训练课题。核心依据为薛锡瑞等《基于桥接分布的无人机集群作战意图推断》：集群运动模型、马尔可夫桥接、条件卡尔曼滤波、目的地与抵达时刻的贝叶斯推断。[S1，第1、2节]

本次交付是**实现规范、接口契约和数学核验材料**，不是已经完成的预测服务。附带的检查脚本只核验数据契约与局部数学性质，不代表完整算法准确率或实用性已经验证。

## 1.1 已确认的需求

推断单位是上游已经划分的集群；成员数为1时仍是合法集群。对每个集群、每个候选重要设施，输出目标趋向概率和条件抵达时间分布，供下游威胁分析使用。外部继续提供现有轨迹 JSON 与 Airspace JSON，不要求增加速度、真实目的地、真实抵达时间或时间先验字段。样例文件只用于识别字段结构，不以本次样例的数值制定算法规则。

本模块不负责检测、目标身份关联、聚类、攻击/侦察等战术类别识别、最终威胁评分或处置控制。内部速度估计属于状态空间推断的一部分，不是重新开发前端目标跟踪系统。

## 1.2 来源与新增内容标记

文中使用四类标记，避免将工程补充误写为论文已实现的能力：

| 标记 | 含义 |
|---|---|
| [P] | 原论文明确给出的模型、方法或实验设置 |
| [D] | 根据论文公式独立推导或进行的数学核对 |
| [E] | 为本项目提出的接口、算法或数值实现适配 |
| [C] | 部署前需配置或标定的业务/统计参数 |

“默认”只表示本规范提出的开发默认值，不等于用户已经批准业务阈值，也不等于论文验证过这些取值。

## 1.3 本版冻结内容

冻结外部字段映射、集群为推断单位、位置量测接口、输出概率语义、证据去重原则、模块职责与测试要求。第一版执行方式冻结为**每次快照内重建并递推**：使用本次自包含历史窗口完成一次推断，不把上次的后验再乘以本次重复历史的似然。

抵达事件第一版明确命名为 `GROUP_TERMINAL_STATE`，对应论文的联合终端状态约束；不得把它改名为“首次进入防护圈”。防护圈首入时间保留独立扩展接口，未实现时返回 `NOT_IMPLEMENTED`，不是返回由中心时间减去半径/速度得到的替代值。

可达域重加权保留为独立插件，但不默认进入正式概率输出。其原文存在需要解决的实现歧义，见第10节与《数学核对记录》。基础桥接推断可以先完成，不用等待该插件。

# 2. 预测量与业务语义

设集群为 $g$，成员数为 $N_g$，候选设施为 $D_1,\ldots,D_M$，本次有效观测参考时刻为 $t_*$，预测时域为 $H$。第一版同时维护设施终端假设和一个自由运动替代模型 $H_0$。[E]

设施假设 $H_j$ 的含义是：该集群具有共同目的地 $D_j$，且终端时刻 $T$ 落在本次设定的未来搜索区间内。输出：

$$
p_j=P(H_j\mid Y_{\mathrm{eval}},Y_{\mathrm{init}}),
\qquad
p_{j,r}=P(H_j,T\in B_r\mid Y_{\mathrm{eval}},Y_{\mathrm{init}}).
$$

其中 $Y_{\mathrm{init}}$ 只用于初始化，$Y_{\mathrm{eval}}$ 只用于后续似然更新；$B_r$ 是到达时间网格单元。两段观测不能重复计入证据。

## 2.1 必须区分的四个量

**当前接近状态**表示距离是否缩短，可从平滑位置和速度推导；它不是目的地概率。

**设施终端假设概率**表示在模型、候选集合和预测时域下，某设施终端假设解释观测的相对可能性；它不是攻击概率，也不是已校准的真实世界风险。

**条件终端 ETA**是在 $H_j$ 成立的条件下，对 $T-t_*$ 的概率总结。设施假设概率很低时，也可能存在数学上很集中的条件 ETA，不能脱离 $p_j$ 单独展示。

**区域首次进入时间**是未来路径首次与某个区域相交的时刻。这是另一个随机量，不等价于前述终端时间。不同设施的区域可能重叠，其进入概率也不要求总和为1。

## 2.2 原论文实际约束的终端

论文式（18）令整个集群的终端状态 $X_T$ 服从以目的地状态为均值的高斯分布；终端位置有扩展范围，速度有许可偏差。论文实验使用零终端速度。[P；S1，第3页式（18）、第7页第3.2.1节]

因此，原模型不是“只约束质心”的模型，也未定义“首架/多数/全部成员首次进入圆形保护区”的时间。此前讨论中将质心抵达作为第一版默认，是可选工程简化，不能称为与原文严格一致。本规范改为明确保留论文的联合终端状态语义，并把质心和首入区域留在独立扩展层。[D/E]

## 2.3 自由运动替代假设的解释

$H_0$ 使用不附带设施终端条件的运动模型。它可以吸收路过、未建模目的地、当前窗口中没有明显设施趋向、时域外抵达等情况，但不能区分这些原因。输出名采用 `unresolvedModelProbability`，语义为模型集合中的替代模型质量，不得宣称它是经过证明的“绝对不会到达任何设施的概率”。[E]

当所有模型均严重失配时，即使归一化后某个概率很高，也应返回 `MODEL_MISMATCH` 或 `INSUFFICIENT_EVIDENCE`。概率竞争不能替代绝对拟合诊断。

# 3. 外部输入与现有接口兼容

## 3.1 轨迹 JSON

保留原结构：[S2；S4，第3.2节]

```text
uavs_coords_str[targetId]
    lngs: number[]
    lats: number[]
    alts: number[]     # 可选；存在时等长
    ts: integer[]     # Unix 毫秒时间戳
```

读取 `requestId`、`snapshotTime` 作为业务关联信息；读取 `targetAttributes[targetId].altitudeReference` 作为高度元数据。其他业务字段透传或忽略，不为本模块修改其原有含义。

现有 v3.2 文档要求每目标至少6点、`lngs/lats/ts` 等长、时间戳严格递增；建议请求携带自包含历史窗口。[S4，第3.2节] 本模块不修改公共 API 校验规则。离线适配器可另设“排序/去重并记录诊断”的宽容模式，但必须与 HTTP 严格模式分开，不能静默放宽既有接口。

ID 始终作为字符串保存，不能把长整型 ID 转成浮点数。坐标必须有限，不能接收 NaN/Infinity。`alts` 缺失不阻断二维推断；不得补零后冒充真实高度。

## 3.2 Airspace JSON

遍历 `data.list[*].facilityList[*]`，读取设施 `id/name/lng/lat`，同时保留父级防控区 `id` 与区域属性。[S3]

内部 `Facility` 至少保存：`facilityId`、`airspaceId`、`name`、`longitude`、`latitude`、`coordinateReference`。区域几何、半径及高度限制作为独立元数据，不直接混入目的地高斯协方差。

`warningRadius/alertRadius/countermeasureRadius` 位于父级防控区。若一个防控区包含多个设施，原 JSON 结构不足以证明这些半径分别以每个设施为圆心。`warningGeom/alertGeom/countermeasureGeom` 的几何结构、坐标系和与设施的对应关系也不能从值为 null 的样例推断出来。未配置映射规则时，区域功能返回 `REGION_MAPPING_UNCONFIRMED`，中心候选推断仍可工作。[E/C]

同一设施 ID 在多个防控区重复出现时，中心目的地不得重复获得先验质量。位置一致则合并候选并保留多个关联；位置冲突则报配置错误。不同 ID 的同址设施应记录不可分辨性，禁止靠任意排序宣称识别成功。

## 3.3 集群输入是内部适配契约

原始两个 JSON 不增加必填字段。聚类完成后，由现有系统把结果转换成下面的内部对象：[E]

```json
{
  "groups": [
    {
      "groupId": "本轮上游集群ID",
      "memberIds": ["目标ID-1", "目标ID-2"],
      "membershipValidFromMs": null
    }
  ]
}
```

现有文档的路径是 `clusterDtoList[].clusterId` 及其成员列表，且明确说明 `clusterId` 跨快照不稳定。[S4，第5.4节] 第一版不得以这个 ID 作为长期滤波缓存键。成员按字符串 ID 排序后确定矩阵顺序，输入顺序变化不得改变结果。

同一分组批次默认是互斥划分。成员缺失、重复归属、空群分别报告诊断；不得悄悄把三机群改成二机群继续输出相同群语义。未分组目标是否补成单机群由上游资格规则决定，不能恢复已经豁免或排除的目标。

当前成员关系并不证明过去整段轨迹期间成员始终同群。上游若提供 `membershipValidFromMs`，推断窗口从该时刻之后截取；未提供则标记 `MEMBERSHIP_HISTORY_ASSUMED`，并用短窗口/一致性检查控制风险。

## 3.4 与旧输出的关系

v3.2 的旧 `eta` 指向最近设施，`etaMethod` 使用旧估计器或直线匀速方法，`arriveTime` 由 `snapshotTime + eta` 得到。[S4，第5.4节] 新模块输出“多个候选设施下的条件时间分布”，含义不同，第一版不覆盖这些字段，也不把新统计概率塞入原来的规则 `confidence`。

建议内部新增 `facilityArrivalInference` 结果对象，经版本化接口变更后再决定公开挂载位置。尚未检查实际仓库，因此本规范不宣称公共接口中已经存在该字段。

# 4. 标准化、时间处理与位置量测

## 4.1 坐标转换

无人机与设施先统一地理坐标系，再转换到同一个局部米制坐标框架。输入没有明确坐标参考时，由系统级配置给出，不能凭经纬度数值猜测 WGS84/GCJ-02 等标准。[E/C]

投影原点、坐标变换版本必须随结果记录。局部平面适用范围作为配置与验证项；超出范围时按区域拆分或使用合适投影，不硬套单一局部平面。高度第一版仅作为辅助元数据；三维空域判别需另行统一高度基准。

## 4.2 时间参考与异步更新

将 Unix 毫秒时间转成相对秒进行矩阵运算，保留绝对毫秒用于输出。基准时刻为本次选定共同观测窗口内所有必要成员均具有有效覆盖的最后参考时刻 $t_*$，不得把较新的 `snapshotTime` 当作新增位置观测。

推荐采用成员观测时间的有序并集做事件驱动更新：传播整个联合状态，但每次只更新真正收到位置的成员。缺少量测的成员只预测，不补造量测。这可以避免为同步而插值后，把插值点当独立证据。

每个假设必须使用相同的一组观测、相同观测顺序与相同量测噪声规则。不能为了让某一设施假设更匹配，而只在该假设内丢弃不符合的真实观测。

## 4.3 只用位置作为观测

内部物理状态按成员排列为：

$$
X_t=[x_1,v_{x,1},y_1,v_{y,1},\ldots,x_N,v_{x,N},y_N,v_{y,N}]^\top.
$$

单成员位置量测矩阵为：

$$
G_i=\begin{bmatrix}1&0&0&0\\0&0&1&0\end{bmatrix}.
$$

联合量测矩阵按实际到达的成员选行；观测噪声使用对应子块 $V_n$。这是对论文通用量测式（17）的明确工程实例化。[P/E]

差分或窗口拟合只用于初始化与独立的运动摘要。**不能把同一坐标产生的差分速度，再与这些坐标作为互相独立的量测重复送入滤波器。** 本版使用初始化前缀估计状态及协方差，后续原始位置负责更新。

初始物理速度与论文第二状态量的关系需要转换，不能简单按名称对应，详见第6节。

## 4.4 初始化和评价观测分离

每成员选取最早的有效初始化前缀，默认开发样例使用3个不同时间点；得到物理位置、速度及协方差后，传播到一个共同初始化时刻 $t_0$。参与初始化的量测全部记为已消费。仅 $t>t_0$ 的真实量测构成似然评价集。

“至少6点”是现有输入契约，不意味着6点在任何采样率下都足以识别目的地。有效时间跨度、位移相对噪声、剩余评价量测数量均需独立检查。无评价量测时不把先验作为有效预测输出。

# 5. 候选设施、时间网格与先验

## 5.1 无需外部抵达时间字段

先验来自内部配置与允许使用的初始化信息。第一版采用统一的有限预测时域，而不是要求调用方提供真实 ETA：[E]

$$
T\in[t_*+\tau_{\min},\ t_*+H].
$$

$H$、$\tau_{\min}$ 与网格密度是计算/业务配置，不是无人机真实能力的声明。开发配置给出可运行示例值，但生产环境必须明确有效预测范围。窗口不足造成的截断通过诊断暴露，不输出“超过时域所以永不到达”。

如果已知可信的平台速度上限，可用它进行保守可行性分析；只有位置轨迹不能证明真实最大速度。$d/v_{\min}$ 不是允许绕行、悬停情况下的严格到达时间上界。基于同一评价轨迹反复生成集中先验、再计算同一轨迹似然，会重复使用证据，第一版禁止这样做。

## 5.2 先验质量与时间单元

令 $\pi_0$ 是替代模型先验，设施权重 $a_j$ 满足 $\sum_j a_j=1$：

$$
\pi_j=(1-\pi_0)a_j.
$$

初始可采用设施等权。设施“需要重点保护”不等于来机更可能选择它；设施重要性默认留在下游威胁评分，不自动作为目的地先验，避免重复加权。[E/C]

将时间区间分为 $Q$ 个单元 $B_r=[b_r,b_{r+1})$，使用中点 $T_r$ 代表单元，先验质量为：

$$
q_{j,r}=\int_{B_r}p(T\mid H_j)\,dT,
\qquad \sum_rq_{j,r}=1.
$$

均匀先验下 $q_{j,r}=(b_{r+1}-b_r)/(H-\tau_{\min})$。加密某个设施的时间网格不能使该设施凭空获得更多先验概率。

论文使用辛普森积分与离散时间权重；本版采用单元质量/中点积分来统一目的地与时间后验，是明确的数值实现变更，而不是声称逐字照抄式（40）。[P/E；S1，第6页式（39）—（44）]

## 5.3 时域边缘与候选集合

若后验主要集中在首尾时间单元，标记 `HORIZON_EDGE_MASS`，保留分布但可抑制单值 ETA。调整时域后必须重新计算本次窗口内的全部先验和似然，不能在已归一化后验上随意新增有权重候选。

候选集合变化会影响概率解释。结果记录 `candidateSetVersion`、`horizonSeconds` 和 `timeGridVersion`。因性能而排除的设施返回 `NOT_EVALUATED`，不能显示为概率0，也不能偷偷只对 Top-K 重新归一化后伪装为全设施概率。

# 6. 集群运动模型及论文公式适配

## 6.1 模型组成与单机退化

论文模型包括群内速度协调、成员间吸引/排斥、目的地信息与运动噪声。[P；S1，第2页式（1）—（10）] 成员数为1时群内差分协调项和势场和为0，核心桥接与目的地推断仍可使用。

但“可退化为单机”不表示可以直接求逆论文矩阵，也不表示差分速度等于论文式（1）的第二状态。两项均需显式处理。[D]

## 6.2 将论文变量转换为实际物理速度

为避免符号混淆，暂把原文第二状态记作 $u_i$。按式（1）直接展开：

$$
dx_i=[-\gamma(x_i-d)+u_i]dt,
$$

$$
du_i=[\alpha(\bar u-u_i)+\beta r_i(x)]dt+\sigma dW_i.
$$

因此，由位置差分得到的实际速度为：

$$
v_i=u_i-\gamma(x_i-d).
$$

这是对原文方程的代数核对；原文仍将第二状态称为速度，并在实验中另以位置差分计算实际速度。[D；S1，第2页式（1）、第6页图6说明]

在同一集群共享固定目的地 $d$、且所有成员使用相同 $\alpha,\gamma$ 的假设下，上式可严格变换为：

$$
dx_i=v_i\,dt,
$$

$$
dv_i=[-\gamma v_i+\alpha(\bar v-v_i)
+\alpha\gamma(\bar x-x_i)+\beta r_i(x)]dt+\sigma dW_i.
$$

目的地从连续漂移项中消去，但仍通过桥接终端条件进入推断；这不是删除目的地推断。对两个水平轴分别构造并按成员顺序排列。$N=1$ 时成为 $dx=vdt,\ dv=-\gamma vdt+\sigma dW$。[D]

本版选择这一**物理状态表达**，以便直接对接位置量测和差分初始化。变换必须同时作用于初始/终端均值与协方差，不能只改状态方程。附录给出矩阵变换和独立检查脚本。

## 6.3 势场的工程解释

由论文势函数 $U(d)$ 实现二维力时，采用：

$$
\mathbf r_{ij}=-U'(d_{ij})\frac{\mathbf p_i-\mathbf p_j}{d_{ij}}.
$$

标量分段函数来自式（4）—（5），补充方向向量是二维实现所需的明确解释。[P/E] 必须验证近距排斥、远距吸引与 $d=d_r$ 平衡。$d=0$ 以及 $d\to d_m$ 的奇异性、$d\ge d_m$ 的处理在工程上需要正则化规则；任何截断或平滑均作为参数化扩展记录，不能宣称未改变原公式。

初版开发允许设置 `potentialMode=disabled` 单独验证线性桥接内核；它不是完整集群模型交付。势场开启是完整集群模型里程碑的一项验收要求。

## 6.4 时间离散化与高斯近似

在一个冻结漂移片段内：

$$
dX=(AX+h)dt+L\,dW,
\qquad Q_c=LL^\top,
$$

$$
F(\Delta)=e^{A\Delta},\qquad
m(\Delta)=\int_0^{\Delta}e^{As}h\,ds,
$$

$$
Q(\Delta)=\int_0^{\Delta}e^{As}Q_c e^{A^\top s}\,ds.
$$

使用分块矩阵指数或数值积分，不显式计算 $A^{-1}$。论文式（15）的符号及可逆性与其 SDE 需要核对，本版依据上面与 SDE 一致的积分式实现，并记录为独立修正。[D]

$r_i(x)$ 是状态相关的非线性项，所以完整模型不自动具有精确线性高斯转移。本版对每个假设、每个观测更新区间在当前均值处冻结势场；同一次桥接分解的两个子转移必须使用一致的冻结规则。这样得到的是**局部高斯近似**，不能声称全局精确解。长预测区间的误差必须在测试中体现。[D/E]

噪声第一版选择各成员、各轴独立加速度驱动；这是对原文噪声矩阵维度与相关性未充分明确部分的工程实例化。若未来改成共享噪声，需重新验证群内协方差和似然校准。

# 7. 桥接条件转移与状态滤波

## 7.1 条件转移的稳定表达

对设施 $j$、时间单元 $r$，设下一量测时刻为 $t'$，终端为 $T_r>t'$。两个基础转移为：

$$
X_{t'}\mid X_t\sim\mathcal N(F_hX_t+m_h,Q_h),
$$

$$
X_T\mid X_{t'}\sim\mathcal N(F_bX_{t'}+m_b,Q_b).
$$

定义：

$$
S_b=F_bQ_hF_b^\top+Q_b,
\qquad K_b=Q_hF_b^\top S_b^{-1},
$$

$$
A_b=F_h-K_bF_bF_h,\qquad B_b=K_b,
$$

$$
c_b=m_h-K_b(F_bm_h+m_b),
\qquad C_b=Q_h-K_bF_bQ_h.
$$

则：

$$
X_{t'}\mid X_t,X_T\sim
\mathcal N(A_bX_t+B_bX_T+c_b,C_b).
$$

这是论文式（23）—（25）的等价条件高斯形式，避免分别求 $Q_h^{-1}$ 与 $Q_b^{-1}$。[D] 编程中使用线性方程求解或 Cholesky，公式中的逆不对应 `np.linalg.inv`。

## 7.2 终端状态增广

定义 $Z_t=[X_t^\top,X_T^\top]^\top$，维度为 $8N$。其转移为：

$$
R=\begin{bmatrix}A_b&B_b\\0&I\end{bmatrix},\quad
b=\begin{bmatrix}c_b\\0\end{bmatrix},\quad
U=\begin{bmatrix}C_b&0\\0&0\end{bmatrix}.
$$

目的地终端先验 $X_T\sim\mathcal N(a_j,\Sigma_j)$ 随所有更新保留。[P；S1，式（18）、（26）—（28）] 第一版采用分块独立的初始化联合先验；初始与终端交叉块设为0，明确记录这一初始化假设。

量测矩阵增广为 $\widetilde G=[G,0]$。对每条新位置量测执行预测、创新计算、似然计算、后验修正。创新协方差：

$$
S_n=\widetilde G P_n^-\widetilde G^\top+V_n.
$$

对数似然：

$$
\ell_n=-\frac12\left(k\log(2\pi)+\log|S_n|
+e_n^\top S_n^{-1}e_n\right).
$$

状态协方差采用数值稳定更新，保持对称与半正定。严重病态矩阵必须报告，不能无上限添加 jitter 后继续给出高置信结论。

## 7.3 终端时刻处理

每个用于评价的观测时刻必须早于候选终端。不要在 $T=t'$ 时照抄涉及零时间过程协方差的求逆公式。第一版未来网格与观测窗口分离，从构造上避免这一端点；数学单元测试仍需验证趋近终端时的不确定性收缩。

假设实际目标已经处于设施附近，不代表已经“完成了模型终端事件”。当前位置区域关系单独报告，是否继续预测离开/再入不在第一版中自动处理。

# 8. 联合后验与无设施终端模型

## 8.1 每个假设的证据

累计评价区间内对数似然：

$$
\log L_{j,r}=\sum_n\ell_{n,j,r}.
$$

同时用自由运动模型 $H_0$ 对**相同的位置量测**计算 $\log L_0$。第一版 $H_0$ 为物理位置/速度下、不附带终端条件的近似匀速随机加速度模型，可与集群相关项组合；噪声参数需单独标定，不能任意增大以“包容所有未知”。[E/C]

未附带终端条件不等于真正未知目的地的完整生成分布，因此所有输出明确为当前模型集合下的后验。

## 8.2 归一化

$$
s_{j,r}=\log\pi_j+\log q_{j,r}+\log L_{j,r},
\qquad s_0=\log\pi_0+\log L_0.
$$

通过 log-sum-exp 计算统一归一化常数 $Z$，再输出：

$$
p_{j,r}=\exp(s_{j,r}-\log Z),\quad
p_j=\sum_rp_{j,r},\quad p_0=\exp(s_0-\log Z).
$$

保证 $p_0+\sum_jp_j=1$。只有一个设施时仍存在 $H_0$ 竞争，不会因候选数量为1而被结构性强制为1。

如 $p_j$ 在数值上近零，条件时间分布不再除以极小数，应返回 `LOW_DESTINATION_SUPPORT`。不要为得到非零概率而偷偷把所有权重截断为固定下限。

## 8.3 条件时间与近时域终端质量

$$
w_{j,r}=p_{j,r}/p_j.
$$

保留时间网格与完整权重，输出 MAP、均值或中位数中的明确一种作为主摘要；本版开发默认主摘要为中位数，另保留 MAP 与等尾区间。多峰时输出 `MULTIMODAL`，不得把两峰之间的均值描述为最可能时刻。

对 $0<h\le H$，可计算：

$$
P(H_j,T\le t_*+h\mid Y)\approx
\sum_{r:T_r\le t_*+h}p_{j,r}.
$$

输出名为 `terminalHypothesisMassWithinSeconds`，不是“未来 h 秒进入设施圈的概率”。去往其他设施或属于 $H_0$ 的轨迹同样可能路过该圈，因此区域进入概率必须对所有相关路径假设计算。

# 9. 快照执行、动态集群与证据生命周期

第一版入口建议为纯计算函数：

```python
infer_snapshot(trajectory_payload, airspace_payload, groups, config)
    -> FacilityArrivalInferenceResult
```

一次调用内：解析 → 标准化 → 选窗口 → 初始化 → 建立假设库 → 逐观测更新 → 后验汇总 → 质量判定 → 输出。不会跨请求累计已经消费过的历史证据。[E]

这与现有接口“一次请求携带一个自包含业务快照”的形式兼容，并避免依赖不稳定的跨快照 `clusterId`。[S4，第3.2、5.4节]

相同数据、成员集合、设施版本、配置版本必须产生相同结果。滑动窗口变化会改变可用证据；它是有限窗口推断，不宣称等价于从首次发现以来的完整递归贝叶斯后验。

成员增减、分群、并群或分组历史不明时，第一版重新建立该次快照假设库，不复用维度不兼容的联合协方差。不额外开发目标聚类。

后续确有性能需要时，可增加有状态增量模式；必须先落实稳定目标身份、成员谱系、已消费观测键、回溯更正、候选集合变化和时域扩展策略。本版不提前用不稳定群 ID 实现缓存。

# 10. 可达域插件与区域进入扩展

## 10.1 论文可达域重加权

论文根据目的地是否位于预测可达域，对每步量测似然乘 $\alpha_m$ 或 $1-\alpha_m$，其中 $0.5<\alpha_m<1$；实验使用 $\delta=75$、$\alpha_m=0.8$。[P；S1，第5页图3、式（32）—（36），第7页第3.2.1节]

实现前需解决：近远候选边界如何产生；二维势场的边界条件；到 $T$ 的预测是否仍带终端条件；零剩余时间协方差如何处理；与新增 $H_0$ 比较时修正因子的统计语义。

尤其不能先用“必定在 T 到达 D”的条件模型把轨迹拉向 D，再用其终端位置包含 D 证明“D 可达”。在精确桥接端点，终端由条件约束，这种检查可能退化为自我验证。[D]

本版规定：先交付 `basePosterior`；插件默认 `disabled_pending_definition`。可以独立做不附带终端约束的自由预测或可信运动能力检查，作为 `feasibilityDiagnostics`，但这不是原文可达域算法的等价复现。若启用启发式重加权，输出 `reweightedScore` 与方法标识，不能覆盖原后验或宣称天然概率校准。[E]

## 10.2 防护区域首次进入时间

当业务确认区域映射及“首机/质心/全部成员”定义后，独立实现路径事件计算。质心首入圆形区域可定义为：

$$
\tau_{\mathrm{entry}}=\inf\{s\ge0:
\|\bar{\mathbf p}(t_*+s)-\mathbf d_j\|\le R_j\}.
$$

该扩展必须生成或近似未来路径分布，覆盖各设施终端假设及 $H_0$；在有限时域内未进入的样本保留为右删失/未进入质量，不把其 ETA 强行赋成 $H$。采样时必须保留时间相关和群内相关，不能独立抽样每个时刻后计算首入时间。[E]

当前已在区域内时，`ALREADY_INSIDE` 与将来再入是不同问题。圆形半径与高斯协方差不能直接等同；设施区域化不是把 `radius` 填进 `Sigma_d` 即完成。

本扩展不阻断论文终端推断内核开发，但在未实现前，业务不得把该内核的 ETA 当作防护圈首入 ETA。

# 11. 输出契约与质量状态

输出对象保留 `requestId`、`schemaVersion`、`algorithmVersion`、`configVersion`、`sourceSnapshotTime`、`asOfTimeMs`、`probabilitySemantics`、`calibrationStatus` 以及集群结果。

每个集群结果含 `groupId`、`memberIds`、`groupSize`、`status`、`qualityFlags`、`unresolvedModelProbability`、`facilityPredictions[]`。每个设施结果包含设施与防控区关联、目的地后验、条件时间摘要和可选时间网格。详见随附 `output.schema.json` 与示例。

## 11.1 推荐状态

| 状态 | 处理 |
|---|---|
| `OK_MODEL_OUTPUT` | 数学计算与输入检查通过；仍需读取校准状态 |
| `INSUFFICIENT_EVIDENCE` | 不输出有效目的地概率或 ETA，不用先验冒充结果 |
| `MODEL_MISMATCH` | 模型整体拟合异常，保留诊断，要求复核 |
| `INVALID_INPUT` | 本群无法构造一致输入；其他群可独立处理 |
| `NO_CANDIDATES` | 无有效设施候选，不伪造空集合后验 |
| `CONFIG_REQUIRED` | 缺坐标参考、终端配置等必要配置 |
| `RESOURCE_LIMIT` | 计算预算不足，不把未计算项写成0 |

`null` 表示未计算、不可支持或不适用；0表示已计算的零值。两者不可互换。未训练神经网络不等于不需要标定；未标定输出统一带 `calibrationStatus=UNCALIBRATED`。

## 11.2 条件时间字段

`arrival.event=GROUP_TERMINAL_STATE`；`arrival.subject=GROUP_JOINT_STATE`；`arrival.conditionalOn` 明示设施终端假设。字段可含 `etaMedianSeconds`、`etaMapSeconds`、`intervalSeconds`、`intervalMass`、`gridResolutionSeconds`、`status`。

所有 ETA 相对 `asOfTimeMs`，绝对时间由它加 ETA 得到。不能沿用旧接口的 `snapshotTime + eta` 而不核对两者时间差。高斯终端容差和时间网格导致的近似也必须在元数据里可追溯。

## 11.3 供单机威胁分析的使用方式

成员数为1时，该群结果就是单机结果。多机时，目的地概率是共享群假设的证据；可由成员引用，但必须标记 `evidenceScope=GROUP`。不得复制为每机独立概率后再相乘、累计或当作独立确认次数。

下游已有单机距离、接近状态和威胁分与本模块结果并存，不因同群成员的高风险而覆写全部单机威胁。[S4，第5.8节及后端集成说明]

# 12. 参数配置与标定计划

所有参数进入版本化配置，不散落硬编码。原论文参数仅放在 `paper_reference` 配置段，便于核验公式，不直接视为应用最优参数。[P/E]

| 参数组 | 内容 | 来源/要求 |
|---|---|---|
| 输入适配 | 坐标参考、严格/离线模式、窗口、共同时间覆盖 | [E/C] |
| 初始化 | 前缀长度、位置噪声、初始速度不确定性 | [E/C] |
| 连续模型 | $\alpha,\beta,\gamma,\sigma_x,\sigma_y$ | [P]有实验值；迁移需标定 |
| 群内势场 | $d_r,d_m,R_{11},R_{12},R_{21},R_{22}$ | [P]，边界正则化属[E] |
| 终端条件 | 位置扩展、速度均值/协方差、坐标转换 | [P/E/C] |
| 先验 | $\pi_0,a_j,H,\tau_{\min}$、时间单元 | [E/C] |
| 替代模型 | 无终端运动模型及过程噪声 | [E/C] |
| 可信控制 | 创新诊断、条件支持度、时域边缘、多峰 | [E/C] |
| 可达域 | $\delta,\alpha_m$、插件实现版本 | [P]值仅供参考，默认关闭 |

位置噪声协方差单位为平方米，不能把标准差与方差混用。过程噪声强度不是逐采样的固定位置方差；$Q(\Delta t)$ 必须随实际时间间隔变化。

终端速度不能无条件沿用零速度。开发可先使用明确标注“论文式停靠假设”的配置验证；实际设施飞越/接近场景需选定较宽的终端速度分布或其他经过验证的终端模型，记为工程变更。未确认时不得宣称输出是生产可用设施抵达时间。

最少需要代表性的历史/仿真动态轨迹用于标定与测试，其中必须包括非设施趋向、路过、悬停及目标改变。真值只进入离线评测，不进入在线输入。采用场景级划分，不能把同一航迹的滑动窗口随机分到标定和测试两侧。

# 14. 测试与验收

## 14.1 自动化正确性测试

必须覆盖：输入等长/时间戳/ID校验；原样例字段解析；成员排序不变性；单机退化；物理速度变换等价性；奇异 $A$ 的积分；$Q$ 半正定；桥接条件高斯与直接联合条件化一致；观测子集更新；归一化与网格加密质量守恒；重复快照幂等；初始化证据不重复；旧接口字段不被覆盖。

附带 `checks/check_math.py` 与 `checks/check_contracts.py` 仅实现其中一部分独立核验，详见检查报告。Codex 仍需为实际实现补齐测试，不得把附带脚本通过等同为预测内核完成。

## 14.2 功能场景

| 场景 | 预期检查 |
|---|---|
| 单机/多机共同目的地 | 接口与内核均可运行，真值属于候选集合 |
| 一个设施但轨迹路过 | 不因候选为1强制概率1；允许替代模型竞争 |
| 多个接近方向相似的设施 | 证据不足时保持歧义，不强行唯一识别 |
| 非零终端速度 | 验证停靠假设迁移边界 |
| 悬停/绕行/中途转向 | 不用 $d/v$ 除零或硬性排除真实时间 |
| 异步/缺测/重复请求 | 不伪造量测、不重复证据 |
| 分群/并群/成员换序 | 不复用错误维度或成员映射 |
| 同址设施/重叠区域 | 正确报告不可分辨和不同概率语义 |
| 时域外到达/已在区域内 | 截断与现状独立表达，不伪造ETA |
| 多群多设施并发 | 记录延迟、内存与退化状态 |

## 14.3 评测指标

目的地评测至少包含含替代模型的混淆情况、误判设施趋向比例、对数损失/Brier分数或校准图。ETA 评测注明条件：真实目的地已知情况下的时间误差，与选择错误设施后的端到端结果分开报告；同时报告输出覆盖率，不能只在成功样本上汇总。

区间评测记录名义覆盖率与实际覆盖率、宽度和多峰比例。区域首入扩展另测首入真值、未入时域质量与离散步长收敛，不沿用终端时间真值。

系统评测记录每次快照的群数、成员数分布、设施数、时间单元数、事件数、耗时与峰值内存。规模与频率尚无用户确认值，因此本版不承诺毫秒级 SLA，也不预设部署机器。

工程上线门槛由业务方配置允许误报/漏报和时间误差预算。文档不编造一个通用“达到90%即可上线”的阈值。未通过独立动态轨迹验证前，只允许影子运行或人工复核使用。

# 15. Codex 分阶段执行计划

## M0：仓库核对与兼容层

先读取现有工程、接口与聚类调用位置，确认本规范的字段映射是否与实际代码一致。不得直接重写公共 API。交付代码地图、内部对象、输入适配测试与差异清单。

## M1：数值内核与终端桥接

先关闭势场，完成物理状态转换、$F/m/Q$、位置量测、终端增广、对数似然、单机与多机条件高斯测试。通过后增加势场及局部高斯近似，记录近似误差。交付可独立调用的桥接滤波内核。

## M2：设施概率与时间后验

实现设施集合、时间单元质量、$H_0$、统一归一化、ETA和质量标志。快照内重建，不引入跨请求缓存。交付合成输入下的端到端结果与自动化报告；明确尚未标定。

## M3：实际接口接入与参数标定

以不覆盖旧ETA/威胁分为原则接入内部结果；接入代表性动态数据回放，确定终端配置、先验、噪声和质量阈值。输出模型版本、参数版本与独立测试报告。

## M4：可达域及区域事件扩展

先完成原文歧义的技术决策记录，再实现可达域实验插件；对基础后验和重加权结果分别评测。业务确需防护圈首入时，另实现完整路径事件预测并验收。不以一个简化距离/速度公式代替该扩展。

各阶段必须提交：修改文件、运行命令、测试结果、已知限制、下一阶段依赖。不得用写死概率或假ETA通过接口测试；样例输出与计算输出分目录保存。
