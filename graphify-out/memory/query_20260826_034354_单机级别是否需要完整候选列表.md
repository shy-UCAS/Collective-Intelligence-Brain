# Q: 单机级别是否需要完整候选列表

## Answer

建议提供可选的完整候选列表，但不要默认必返。日常业务只需主意图、状态和复核标记；审计、歧义分析及多成员差异排查需要单机候选。候选内部已计算，无额外算法开销，但默认公开会使响应规模约为N乘K。推荐新增options.returnTargetIntentCandidates=false，targetIntentResults[].candidateCount常规返回，开关开启时返回完整topCandidates[]并复用IntentCandidate结构。
