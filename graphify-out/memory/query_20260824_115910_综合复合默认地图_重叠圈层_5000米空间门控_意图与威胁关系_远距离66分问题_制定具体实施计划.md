# Q: 综合复合默认地图、重叠圈层、5000米空间门控、意图与威胁关系、远距离66分问题，制定具体实施计划

## Answer

实施计划以不改变公共DTO结构为约束。问题：默认地图未严格使用原始facilityList[0]且zoneType=2优先Geom；设施全局扁平后无条件选最近；engine先用独立_ring_status/_nearest_facility计算意图威胁，之后AirspaceRelationAnalyzer才生成targetAirspaceResults；普通ring命中cluster.airspaceId可能为空；_approaching前后点可切换最近设施；5000米只过滤movementRelations；空间意图未统一门控，I-26无最大距离；legacy turning阈值20与R6新阈值120混用导致远距离强制66；单一threatScore混合行为风险与设施威胁。用户决策：保留复合地图；每个data.list记录独立，三级半径严格围绕原始facilityList[0]；重叠命中全部保留，标量计算选择一个主上下文；5km按预警圈边界定义空间相关性；圈外仍分析行为但不得把设施威胁强制到66；内部统一SpatialContext且公共输出结构不变；不重新引入主集群/其他集群区别。阶段：1修default_map_refresh并测试首设施和半径；2扩展AirspaceRelationAnalyzer产出public results+context map并提前到聚类前；3让cluster/target/approach/ETA/affectedFacilities共用context；4给空间意图和I-26加门控；5重构threat硬规则，拆R6，spatialRelevant=false时禁用空间floor并将设施threatScore限制低档，分级配置高风险floor；6 event_mapper保持字段集合，matchedRings全返回、primaryRingIds全最高、cluster airspaceId选主、spatialSummary保留全部；7同步defense和routing避免远距离处置；8新增单元、集成、回放和schema快照测试；9更新规则版本、接口文档和修改日志。验收包含远距离北京单设施回放不再66、绍兴本地正常关联、重叠圈全部返回、同级不丢失、I-26远距离不触发、输出schema不变。
