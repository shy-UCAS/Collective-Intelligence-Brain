# Q: 给原始响应 JSON 页面增加 Ctrl+F 开启字段搜索

## Answer

已为 JsonResponseViewer 增加局部 QShortcut(QKeySequence.Find)。当原始响应页内任一子控件获得焦点时，Ctrl+F 会切换到结构树、聚焦字段搜索框并全选已有关键词；不改变其他页面和算法接口。README已补充说明。专项测试使用 QTest 真正发送 Ctrl+F，4项查看器测试及既有26项界面回归全部通过，py_compile和diff check通过。
