# Q: 目前测试按照ZoneType哪些值进行测试

## Answer

所有显式zoneType测试都在 situationawareness latest/tests/test_default_map_refresh.py。基础fixture _airspace_response 固定zoneType=1，test_circle_airspace_becomes_three_polygon_rings_without_no_fly_zone验证三级半径转换为三个12点polygon、airspaceId和relatedFacilityId；test_successful_refresh_installs_runtime_map也复用同一zoneType=1 fixture。test_polygon_airspace_geometry_is_normalized_and_preserved把同一记录改为zoneType=2，只提供warningGeom，并断言warn圈直接保留该polygon；alert与countermeasure未单独断言，但代码会因缺少Geom回退到半径。目前没有显式测试zoneType缺失、null、非法字符串、其他整数、字符串'1'/'2'、zoneType=2且三个Geom全部提供、zoneType=2的Geom非法时回退，以及业务要求始终忽略zoneType只使用facilityList[0]+半径的场景。
