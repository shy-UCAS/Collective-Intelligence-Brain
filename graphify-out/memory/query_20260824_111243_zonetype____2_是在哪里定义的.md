# Q: zoneType == 2 是在哪里定义的

## Answer

实际判断定义在 situationawareness latest/situation_judgment/default_map_refresh.py 的 _ring_geometry：读取 record.zoneType，缺失或转换失败时默认为1；当zoneType==2时优先解析 warningGeom/alertGeom/countermeasureGeom，有有效几何就直接返回，否则回退到 warningRadius/alertRadius/countermeasureRadius 并围绕中心设施离散成多边形。RING_SPECS在同文件31-42行定义三级字段映射。该语义被 README 436-438行和 POST-api-v1-situation-analyze-接口文档-v3.2.md 183-186行记录，并由 tests/test_default_map_refresh.py 78-93行测试固定。仓库中没有独立ZoneType枚举或上游接口模型，因此它是本项目转换层采用的解释，不能仅凭代码确认是上游接口正式定义。若业务真值要求无论zoneType都按facilityList[0]和三级半径构圈，应删除或绕过zoneType==2的几何优先分支，并更新文档测试。
