# Q: 会过滤无效设施后取第一个有效设施，是按什么逻辑过滤

## Answer

default_map_refresh._valid_facilities按facilityList原始顺序遍历。非dict元素跳过；lng和lat经_finite_number转换，布尔值、None、不可转float字符串、NaN和正负无穷返回None并跳过；经度不在[-180,180]或纬度不在[-90,90]也跳过。id缺失不算无效，会生成{airspaceId}_facility_{原始序号}；name缺失也不算无效，用facilityId代替。所有通过项按原顺序组成record_facilities，build_default_map_from_airspace_response取record_facilities[0]作为三级圈层中心。所以原始facilityList[0]无效时会改用后续第一个有效项；全部无效则跳过整个空域记录并写refreshWarnings。
