# Q: 是否应将威胁分也限制在距相关空域边界5公里内，避免1000公里外危险轨迹被R6抬到66

## Answer

担心成立。当前airspaceAssessmentRangeMeters=5000只过滤圈外movementRelations，不约束威胁评分；R6只要heading_change>=120、legacyBehavior.turning或releaseEvent任一成立便无距离条件地把score=max(score,66)，所以1000公里外仍可66。若公共threatScore定义为对当前复合地图设施/空域的威胁，应加入spatialRelevant门控，但不应在5公里外停止所有分析。轨迹、身份、载荷、行为维度仍全局计算；只有空间型意图、空间维度和高分硬规则进入最终设施威胁。推荐spatialRelevant为已命中任一圈层，或位于预警圈边界外airspaceAssessmentRangeMeters以内。相关时正常计算并允许硬规则；不相关时airspaceId/facilityId/affectedFacilities为空，禁止R5/R7/R8/R9和普通转向R6提分，将公共设施threatScore限制在低威胁上限35以保证远距离不会成为高设施威胁。R6拆分：普通或legacy转向只保留behaviorPosture证据，不触发66；确认释放/武器属于全局危险证据。若接口仍只有一个threatScore且业务坚持它代表设施威胁，远处确认释放也不应绑定远方设施，可保留行为证据和复核/事件提示；若还需表达全局危险程度，长期应增加独立overallBehaviorRisk或threatScope，单一分数无法同时准确表达两种语义。
