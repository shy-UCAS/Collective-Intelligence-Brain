# Q: 目前单机以及集群级别的意图，除了最top的意图，会返回一个完整的命中的意图列表吗？

## Answer

当前集群级会公开完整合格候选列表，规范路径为 data.eventSuggestions[].intent.topCandidates[]，索引0与顶层主意图一致；clusterDtoList[]本身只平铺主意图。单机级 data.targetIntentResults[]目前只公开主意图和状态，不包含topCandidates，虽然内部targetThreats[targetId].intent仍保留候选。topCandidates表示所有达到门槛的启用规则候选，并非全部被评估规则。
