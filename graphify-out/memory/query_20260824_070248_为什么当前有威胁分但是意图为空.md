# Q: 为什么当前有威胁分但是意图为空？

## Answer

当前实现中意图识别和威胁评分是两条相关但不互相阻断的链路。evaluate_intent_candidates 无候选时，select_intent 返回 empty_intent，intentLabel/intentName 为 null；_threat 仍继续计算十维分数，空意图在 intent_score 映射中使用默认值18，而非0。本样本的 behavior=85、trend=65、compliance=68、cluster=80、model=55等仍参与加权。更关键的是，大幅航向变化被识别为 evasive_members，触发 R6 规避/俯冲/释放行为威胁下限66，因此加权分即使较低，最终也被 max(score,66) 抬到66。现有19项意图没有对应的通用异常机动候选，其他意图必要条件又未满足，于是出现 threatScore=66、intent=null、reviewRequired=true。语义是风险已出现但行为目的尚不能可靠归类。
