# Q: 态势判读算法单接口协议-v3.2.md 这份接口协议落后于实际代码进度有多少呢

## Answer

核对结论：若只看 POST /api/v1/situation/analyze 的请求体、响应体和 situation-rule-v2.3.0 业务语义，协议约有 90%-95% 已同步；若把完整运行期 HTTP 契约、启动配置、诊断语义和配套样例都算入，约有 80%-85% 已同步。主要差距有五项：1. 实际代码新增 GET /api/v1/situation/metadata 及四个 X-Situation-* 响应头，但协议和 OpenAPI 未说明；2. 默认地图抓取已支持 3 次网络重试、指数退避和环境变量配置，协议只写了刷新失败回退；3. algorithmDiagnostics 实际含 used/not_applicable/partial_fallback/fallback，且队形失败不再用简化算法猜 random，而协议仍只解释 used/fallback；4. 协议链接的完整响应样例仍是 situation-rule-v2.2.2，缺 targetIntentResults、spatialSummary 等新字段；5. 文档日期和 233/236 测试基线过时，当前全量发现为 282 项，1 个旧断言失败和 2 个已知 tests 包导入错误。核心已同步内容包括统一 SpatialContext、5km 关联门控、远场威胁封顶、targetAirspaceResults、targetIntentResults 及默认返回全部意图候选。
