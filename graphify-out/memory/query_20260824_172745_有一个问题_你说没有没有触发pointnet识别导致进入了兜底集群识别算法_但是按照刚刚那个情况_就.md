# Q: 有一个问题，你说没有没有触发pointnet识别导致进入了兜底集群识别算法，但是按照刚刚那个情况，就应该有比如说所有无人机都是孤立点的情况，但是你这么兜底一处理是否反而把本来正常的情况又用兜底算法计算了一遍（而且这个兜底算法本来就有问题，我已经在考虑把队形识别的兜底算法去除掉了）

## Answer

当前样本没有再次执行队形兜底算法。正常流程是DBSCAN先得到12个单目标集群；每个group成员数为1时，LegacyAlgorithmAdapter._recognize_formations直接写formationType=none并continue，既不加载也不调用PointNet。DBSCAN成功，因此SituationEngine中的米制空间聚类兜底也未触发。旧的经纬度包围盒horizontal/vertical/random规则已删除；现存_fallback_formation只返回常量none，不进行几何计算，仅用于PointNet无可靠结果时保持既有formationType枚举兼容。若追求代码语义清晰，可进一步删掉该空壳方法并直接表达override为空则none，但功能上旧队形兜底已经去除。
