# 3 我方拦截时间的估计方法
我方拦截时间（从机库出发）的估计：
| 突破（Penetration）
内涵：集群的主要目标是突破敌方防线，为后续部队或打击防线后方的关键目标开辟道路。
特征：通常以紧密的队形穿越防线，强调快速行动与防线穿透能力。
典型队形：集群向防线方向集中推进。 |  | 特点：
【必要】和我方防御设施距离不断缩小（或飞行轨迹上，我方的防御能力会持续增加）；
【必要】和我方关键设施之间的距离不断缩小；
【非必要】有比较高的飞行速度；
【非必要】有较密级的阵型。
特征：和我方防御设施距离、和我方重要设施距离、与我方重要设施方向夹角、飞行速度变化、和其他个体之间的距离。 |
| --- | --- | --- |
| 迂回（Detour）
内涵：集群的目标是绕过敌方防线，从侧翼或后方发动攻击，从而迫使敌方调整防御部署，削弱其防御阵地的有效性。
特征：以分散或非直线的方式进行移动，形成侧翼或后方威胁。
典型队形：集群以曲线或分离方式绕过防线。 |  | 特点：
【必要】和我方防御设施（无人机机库）保持固定或增加相互距离；（或是飞行轨迹上，我方的防御能力维持不变或减少）
【必要】和我方重要设施维持一定的距离，或绕行过程中缩小距离；
【非必要】绕行过程中发生分群行为，但每个分群都和我方防御设施保持一定距离。
特征：和我方防御设施距离、和我方重要设施距离、与我方重要设施方向夹角、飞行轨迹弯曲、相互之间距离变化。 |
| 侦察（Reconnaissance）
内涵：集群对某一区域进行大范围的侦察和监视，收集目标区域的情报或获取敌方部署信息。
特征：集群中的无人机以分散形式覆盖目标区域，强调全面覆盖与持续监控。
典型队形：集群扩展分散在目标区域上方。 |  | 特点：
【必要】没有明确飞向我方的特定目标；
【非必要】轨迹存在较多弯曲，没有固定的飞行方向；
【非必要】没有密级的队形、为少量的无人机。
特征：轨迹转弯行为、飞行朝向角变化率、和我方重要设施方向夹角、分群情况、相互之间距离变化。 |
| 搜索与打击（Search & Strike）
内涵：集群由搜索和打击无人机组成，搜索指定区域内的潜在目标，并对目标进行快速打击。
特征：搜索无人机负责目标侦测，打击无人机迅速锁定并攻击目标。
典型队形：集群以搜索无人机为前导，打击无人机跟随。 |  | 特点：
【必要】敌方有搜索个体；
【必要】存在我方目标被搜索后不久，敌方个体径直飞往我方目标的行为事件；
【非必要】我方被打击、将要被攻击的目标是被敌方搜索覆盖过的。
特征：搜索个体、搜索覆盖我方设施的事件、飞向我方设施的事件、两种事件的前后衔接。 |
| 快速通过（Fast Pass）
内涵：集群快速通过指定区域，通常保持紧密队形，避免被敌方拦截或干扰。
特征：快速飞行，队形紧凑，减少暴露时间。
典型队形：集群呈现密集的前进队形。 |  | 特点：
【必要】整体飞行速度会突然加快，有显著提速动作；
【必要】相互之间距离较小（以紧凑队形）；
【必要】可能穿过防御区域，但是飞行朝向不是我方重要目标。
特征：飞行速度变化、相互距离变化、航向和我方设施夹角。 |
| 连续打击（Sequential Attack）
内涵：集群按照预定的时间间隔对目标实施系统性攻击，每次攻击由不同的无人机或分队完成。
特征：攻击节奏有序，目标受到连续性威胁。
典型队形：集群中的无人机依次发起攻击。 |  | 特点：
【必要】敌方个体朝同一个我方目标逼近；
【必要】敌方个体达到我方目标的时间有前后差异；
【必要】相互前后之间有比较明显的跟随关系。
特征：飞行轨迹相似性、距离我方设施距离、到达我方设施时间、飞行方向相近性。 |
| 齐射攻击（Salvo Attack）
内涵：集群以同步攻击的方式对目标实施齐射，目的是提高攻击成功率或威胁效能。
特征：集群中的无人机在同一时间点对目标实施协同打击。
典型队形：集群在齐射前保持一致的队形。 |  | 特点：
【必要】敌方个体朝同一个我方目标逼近；
【必要】敌方所有个体预计达到我方目标的时间相同；
【非必要】敌方目标分处不同的编队、以不同的角度逼近我方目标。
特征：飞行朝向相交情况、距离我方设施距离、到达我方设施时间。 |
