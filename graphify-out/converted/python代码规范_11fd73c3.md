适用于所有使用Python语言开发的项目，包括但不限于Web应用、数据科学、自动化脚本、API服务等。

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| 变量/函数 | snake_case | user_name, get_user_data() |
| 常量 | UPPER_SNAKE_CASE | MAX_CONNECTIONS, API_VERSION |
| 类 | PascalCase | UserModel, DataProcessor |
| 模块/包 | lowercase | utils.py, data_processing/ |
| 私有成员 | 前导下划线 | _private_var, _internal_method() |
| 保护成员 | 前导单下划线 | _protected_method() |
| 不允许使用的命名方式 | 单字符（除i/j/k）、保留字 | 避免使用 l, O, list, dict |
